Microfono (dictado)

El audio se graba localmente y se envia al endpoint de transcripcion que configures (compatible con la API de OpenAI: OpenAI, Groq, o tu propio servidor Whisper). El texto resultante se escribe en el terminal.

Sin API key puedes usar el dictado nativo de Windows (Win+H), pero Windows bloquea la escritura del dictado en ventanas elevadas: solo funciona si abres AdminTerm en modo normal.

  • Ctrl+Shift+F buscar
  • Ctrl+Shift+M microfono
  • Ctrl+Shift+O insertar archivos
