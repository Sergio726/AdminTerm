Terminal

Sesion y ventana

Funciona aunque AdminTerm este en segundo plano. Ejemplos validos: Control+Alt+T, Super+Grave, Control+Shift+Space.

Microfono (dictado)

El audio se graba localmente y se envia al endpoint de transcripcion que configures. El texto resultante se escribe en el panel activo.

Con el proveedor Servidor local no hace falta API key: AdminTerm levanta Whisper en tu equipo la primera vez que dictas y lo cierra al salir. Requiere Python con faster-whisper, fastapi y uvicorn. El campo "Modelo" acepta base (mas rapido) o small (mas preciso).

"Probar" envia un audio de un segundo generado al vuelo para comprobar endpoint y credenciales, sin usar el microfono.
